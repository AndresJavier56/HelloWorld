# HelloWorld

My first C# console application
This project demonstrates how to create, built, run, and publish a simple Vs Code, Git, and Github application.

>This project is intended for learning and practice

## Description
 
 HelloWorld is a simple C# console application created as an introduction to .NET development.

The project also demonstrates basic Git and Github workflow, including cloning committing and pushing changes.

## Requirements

- Development tool
- .NET SDK
- VS Code
- Source Control
- Git
- GitHub account

## Getting Started 

1. Clone the repository.
2. open the project folder in VS Code.
3. Run 'dotnet build'.
4. Run 'dotnet run --project "src/HelloWorld"'.

## Usage

Debug the application by Run > Start Debugging (or press F5).

Expected output:

'''text
Hello, World!
'''

'''csharp
Console.WriteLine("Hello, World!");
